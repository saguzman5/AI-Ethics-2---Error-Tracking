Live spreadsheet feed

Google Sheets and Excel read the error reports from this read-only CSV feed. The feed always reflects the current database.

Breaks existing connections until they are updated with the new URL.

Google Sheets (auto-refresh every minute)

  1. Create a Google Sheet, then open Extensions > Apps Script.
  2. Paste the contents of Spreadsheet/google-sheets-sync.gs and set FEED_URL to the URL above.
  3. Run setup once and approve the permissions. The sheet then refreshes every minute.

Google's servers must be able to reach this server over the internet (see Documentation/SETUP.md, “Spreadsheet”).

Microsoft Excel (Power Query)

  1. Data > From Web, paste the URL above, then Load.
  2. Data > Queries & Connections > right-click the query > Properties > tick Refresh every 1 minute and Refresh data when opening the file.
