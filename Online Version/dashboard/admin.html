Add a user

Logins are created in your Supabase project, then given a role here.

  1. Open supabase.com > your project > Authentication > Users.
  2. Click Add user > Create new user. Enter an email (it can be made up, for example jchen@yourcompany.com; no email is sent) and a password of at least 8 characters. Tick Auto Confirm User, then click Create user.
  3. Reload this page. The person appears in the list as a worker. Change the role to manager if needed and click Save.

Workers can only scan products, submit reports and see their own submissions. Managers see everything, update statuses and manage configuration. To reset a password: Supabase > Authentication > Users > the user > Send password recovery, or delete the login there and create it again (only possible if the person has no reports; otherwise deactivate them here).

Google Sheets live sync

Google Sheets copies all error reports from the online database every minute. The database stays the master copy.

Set up

  1. Create a Google Sheet, then open Extensions > Apps Script.
  2. Paste the contents of Spreadsheet/google-sheets-sync-online.gs. Replace the three settings lines at the top with the ones above, then save.
  3. Select the function setup and click Run. Approve the permissions. The sheet then refreshes every minute.

Excel
